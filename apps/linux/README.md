# Takt для Linux

Предварительная версия клиента задач на GTK 4 и libadwaita. В широком окне папки, список и редактор расположены в трёх колонках. Список и редактор разделяет регулируемый разделитель. При сужении папки открываются по кнопке «Папки», а в самом узком режиме редактор занимает окно и возвращает к списку по кнопке «Назад». Оформление следует за системной темой. Используются нативные иконки и контролы GNOME. [GNOME Human Interface Guidelines](https://developer.gnome.org/hig/) · [Libadwaita](https://gnome.pages.gitlab.gnome.org/libadwaita/doc/main/)

В этой версии доступны системные разделы и создание папок, поиск, создание и редактирование задач, отметки «Сегодня» и «Выполнено». Редактор сохраняет текст при явном сохранении, перед переходом к другой задаче или папке и при закрытии окна. Библиотека задач хранится в `$XDG_DATA_HOME/takt/tasks.sqlite3` или `~/.local/share/takt/tasks.sqlite3`. Клиент использует [общее ядро задач](../windows/src/Takt.Core). Синхронизация, заметки, календарь и ИИ-чат относятся к следующим этапам.

## Ubuntu

Установка локального пакета из каталога загрузок. Вместо имени файла подставьте сборку для своей архитектуры (`amd64` или `arm64`):

```sh
sudo apt install ./Takt-Linux-0.1.0-preview.1-amd64.deb
takt
```

## Сборка

На Linux с .NET 10 SDK и `dpkg-deb` из корня репозитория:

```sh
bash apps/linux/scripts/build-release.sh amd64
bash apps/linux/scripts/build-release.sh arm64
```

Скрипт сохраняет `.deb` и его SHA-256 в `dist/`. Второй аргумент позволяет выбрать другой выходной каталог. Для локального запуска из исходников используйте `dotnet run --project apps/linux/src/Takt.Linux`.

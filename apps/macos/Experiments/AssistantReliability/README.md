# Проверка надёжности 4-битного помощника

[Результаты 0.2.2](REPORT.md). Исходные веса не меняются.

Из каталога `apps/macos/`:

```sh
python3 Experiments/AssistantReliability/run.py
python3 Experiments/AssistantReliability/summarize.py
```

Нужны Xcode с Metal Toolchain и тестовая 4-битная модель в `.build/ModelCache4`. Скрипт использует отдельную opt-in схему, вымышленные данные и песочницу тестового приложения. Схема убирается после завершения. Отчёты записываются в `.build/AssistantReliability`.

Базовые входные контексты взяты из предыдущего сравнения; промпты строятся текущим приложением. Восемь новых случаев проверяют папку по умолчанию, папку в кавычках, буквальное название «Отметить на сегодня», независимость звезды и срока, неизвестные назначения и английское событие. Оценка относится к полному пути помощника, включая проверки и нормализацию.

Каждый новый запуск архивирует предыдущие временные результаты в `.build/AssistantReliability/History` и проверяет неизменность исходников и закреплённого манифеста во время прогона. Репозиторные `results` — сохранённый отчёт; скрипт его автоматически не перезаписывает.

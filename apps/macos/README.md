# Takt для macOS

Нужны Mac с Apple Silicon, macOS 26+, Xcode 26 с поддержкой Swift 6.2 и Python 3.

## Заметки

Созданные пользователем папки содержат задачи и заметки. Переключатель над списком доступен только в этих папках. Системные разделы предназначены для задач. «Все заметки» и корзина служат общими представлениями; при создании заметки из них нужно выбрать пользовательскую папку. Старые заметки из системных и удалённых папок остаются в «Все заметки». Заметки поддерживают форматирование, списки, чек-листы, ссылки, изображения, поиск, закрепление, перемещение и корзину с восстановлением. Ввод сохраняется после паузы, при переключении и закрытии приложения.

Заметки хранятся локально рядом с выбранной библиотекой в `Notes.json`. Новые облачные заметки можно редактировать на Mac и Android с сохранением оформления, списков, ссылок и изображений. Для общего формата нужен Takt Server 0.1.4 или новее. Он применяется с момента создания заметки. Резервные копии с заметками общего формата используют версию 3. Приложение также читает версии 1 и 2. Когда открыт ИИ-чат, текущая заметка и её папка появляются в контексте. Текст заметки передаётся модели при отправке. Контекст можно убрать перед отправкой. Предложенный текст можно применить после проверки.

В верхней шапке окна можно записать голос и отправить запись на расшифровку после подтверждения. Модель выбирается в **Настройки → Помощник → Модель для расшифровки**. В этом же разделе подключаются провайдеры и настраивается общий список моделей для чата и расшифровки. Выбор модели чата в настройках и в текущем разговоре общий. В меню чата появляются только добавленные модели с поддержкой чата. Если убрать текущую, для следующего сообщения потребуется выбрать другую. Запись сохраняется целиком, длинное аудио после подтверждения отправляется частями, а готовый текст открывается для просмотра. Нажмите **Вставить в заметку**, чтобы добавить его в конец заметки. Окно можно открыть снова из карточки записи. Для расшифровки доступны OpenRouter, LiteLLM, GigaChat, OpenAI API, Gemini, Mistral и Grok. OpenAI API подключается отдельным ключом. Закреплённые модели отображаются в начале списков. В одной заметке можно хранить несколько записей и менять их названия. Аудиофайлы остаются на этом Mac после перезапуска и расшифровки, пока пользователь их не удалит. Во время записи в шапке доступны пауза, остановка и таймер. Копию аудио можно экспортировать перед отправкой.

Чтобы записать звонок, нажмите «Записать звонок» в верхней шапке, выберите вкладку встречи в Chrome и включите передачу звука вкладки. Запись звука вкладки начинается сразу после выбора. Чтобы добавить свой голос, разрешите Chrome доступ к микрофону. В карточке звонка отдельно видны уровни микрофона и вкладки. Запись можно приостановить и завершить из заметки. После остановки подтвердите отправку на расшифровку.

## Запуск

Откройте `Planner.xcodeproj` в этой папке, выберите **Planner → My Mac** и нажмите **⌘R**.

## Сборка и проверка

### Резервная копия перед переездом

В приложении откройте **Настройки → Резервная копия → Создать резервную копию…** и сохраните JSON-файл вне библиотеки приложения. Экспорт читает данные, доступные на Mac, и сохраняет последние правки открытых задач. Изменения с других устройств попадут в файл, если они уже успели синхронизироваться с этим Mac.

После очистки базы или переезда выберите **Восстановить из файла…**. Проверьте дату и количество задач, затем откройте восстановленную локальную библиотеку. Прежняя база остаётся на диске. Для повторной загрузки в облако войдите в нужный аккаунт и выберите **Перенести задачи и войти**. Для переноса в существующую библиотеку её записи с совпадающими идентификаторами имеют приоритет. История чата и связи с календарём остаются локальными. Сами события хранятся в системном календаре.

Файл содержит личные данные в открытом виде. Храните его в выбранном защищённом месте. Токены, пароли, ключи доступа и техническая очередь синхронизации в файл не входят.

### Команды сборки

Выполняйте команды из корня репозитория. Пакет переводов входит в исходный код.

Скомпилируйте приложение и тестовые исходники без запуска тестов:

```sh
xcodebuild -project apps/macos/Planner.xcodeproj -scheme Planner \
  -configuration Debug -destination 'generic/platform=macOS' \
  -derivedDataPath apps/macos/.build/DerivedData build-for-testing
```

Соберите демонстрационные приложения с вымышленными данными и установочный DMG:

```sh
python3 apps/macos/scripts/prepare_showcase.py
PLANNER_RELEASE_SIGNING_IDENTITY='<certificate fingerprint>' python3 apps/macos/scripts/build_release.py
```

Для DMG с виджетом «Сегодня» нужен сертификат подписи Apple. Для локальной сборки без сертификата передайте `--without-widget`.

Демонстрационные приложения появятся в `apps/macos/.build/showcase/`, а DMG для Apple Silicon и его SHA-256 — в корневом `dist/`.

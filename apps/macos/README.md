# Takt для macOS

Нужны Mac с Apple Silicon, macOS 26+, Xcode 26 с поддержкой Swift 6.2 и Python 3. Для сборки с MLX установите Metal Toolchain через `xcodebuild -downloadComponent MetalToolchain`.

## Заметки

Созданные пользователем папки содержат задачи и заметки. Переключатель над списком доступен только в этих папках. Системные разделы предназначены для задач. «Все заметки» и корзина служат общими представлениями; при создании заметки из них нужно выбрать пользовательскую папку. Старые заметки из системных и удалённых папок остаются в «Все заметки». Заметки поддерживают форматирование, списки, чек-листы, ссылки, изображения, поиск, закрепление, перемещение, корзину с восстановлением и экспорт RTFD. Ввод сохраняется после паузы, при переключении и закрытии приложения.

Заметки хранятся локально рядом с выбранной библиотекой в `Notes.json`. Резервная копия версии 2 включает заметки и вложения. Приложение читает прежние копии версии 1. При входе в облачную библиотеку заметки синхронизируются, если сервер поддерживает заметки. Чтобы передать текст открытой заметки модели, выберите «Использовать заметку» в меню контекста ИИ-чата.

## Запуск

Откройте `Planner.xcodeproj` в этой папке, выберите **Planner → My Mac** и нажмите **⌘R**.

## Сборка и проверка

### Резервная копия перед переездом

В приложении откройте **Настройки → Резервная копия → Создать резервную копию…** и сохраните JSON-файл вне библиотеки приложения. Экспорт читает данные, доступные на Mac, и сохраняет последние правки открытых задач. Изменения с других устройств попадут в файл, если они уже успели синхронизироваться с этим Mac.

После очистки базы или переезда выберите **Восстановить из файла…**. Проверьте дату и количество задач, затем откройте восстановленную локальную библиотеку. Прежняя база остаётся на диске. Для повторной загрузки в облако войдите в нужный аккаунт и выберите **Перенести задачи и войти**. Для переноса в существующую библиотеку её записи с совпадающими идентификаторами имеют приоритет. История чата и связи с календарём остаются локальными. Сами события хранятся в системном календаре.

Файл содержит личные данные в открытом виде. Храните его в выбранном защищённом месте. Токены, пароли, ключи доступа и техническая очередь синхронизации в файл не входят.

### Команды сборки

Выполняйте команды из корня репозитория. В чистой копии загрузите закреплённые Swift-зависимости в каталог, который использует сборка DMG:

```sh
xcodebuild -resolvePackageDependencies -project apps/macos/Planner.xcodeproj -scheme Planner \
  -clonedSourcePackagesDirPath apps/macos/.build/SourcePackages
```

Скомпилируйте приложение и тестовые исходники без запуска тестов:

```sh
xcodebuild -project apps/macos/Planner.xcodeproj -scheme Planner \
  -configuration Debug -destination 'generic/platform=macOS' \
  -derivedDataPath apps/macos/.build/DerivedData \
  -clonedSourcePackagesDirPath apps/macos/.build/SourcePackages build-for-testing
```

Соберите демонстрационные приложения с вымышленными данными и установочный DMG:

```sh
python3 apps/macos/scripts/prepare_showcase.py
python3 apps/macos/scripts/build_release.py
```

Демонстрационные приложения появятся в `apps/macos/.build/showcase/`, а DMG для Apple Silicon и его SHA-256 — в корневом `dist/`. Эксперименты и тесты с реальной моделью используют тестовые веса в `apps/macos/.build/`.

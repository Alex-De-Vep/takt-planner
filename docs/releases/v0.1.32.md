# Tasks 0.1.32 Public Preview

This native macOS planner is available under Apache 2.0. It includes folders, Today, weekly and monthly planning, descriptions, subtasks, and day, three-day, and week views of the system calendar.

## Notifications and calendar alerts

- Changing a task deadline reschedules its notification. Completing or deleting the task or removing its deadline cancels the notification. Reopening an incomplete task restores its notification if the deadline is still in the future.
- Date-only deadlines notify at a configurable local hour, 9:00 a.m. by default. Their day and time follow the local time zone. Timed deadlines retain their original due instant.
- The separate task review reminder is off by default. It can run daily or on weekdays at a chosen local time.
- Settings show notification permission, offer a retry after scheduling errors, and can send a test notification after five seconds.
- The event editor displays every alert, including alerts set for a specific date. Add, edit, or remove alerts individually. The editor preserves untouched special alert actions and reports concurrent alert changes before saving.

macOS notification permission, Focus, and other system settings affect delivery. The app schedules all future deadlines. If macOS limits its pending queue, the app prioritizes the nearest deadlines and repeating reminders, then refills the queue on launch, activation, or task changes. Settings indicate when some deadlines are waiting for the next refill. Past deadlines generate no retroactive notifications. Completing, deleting, or changing a task clears its previously delivered notifications.

## Verification and installation

Previous logs record 37 passing targeted unit tests of notifications, calendar alerts, deadlines, and event moves, four passing localization checks, and two passing UI scenarios for Settings and the event editor. The app and all test sources were recompiled for this release. Tests were not rerun. Automated UI checks use a substitute notification center. Use **Test notification** in the installed app to check macOS permission and banner delivery. Calendar checks use an isolated store and real `EKAlarm` objects without accessing personal calendars.

The universal DMG requires macOS 26 or later and supports Apple Silicon and Intel. It preserves the existing library and app identifier. The app uses a local ad-hoc signature without Developer ID signing or Apple notarization. Gatekeeper may restrict launching the downloaded build on another Mac. The source is available for building in Xcode.

The DMG was mounted read-only. Both architectures, the signature, entitlements, names, app icon, LICENSE, and NOTICE were checked. A SHA-256 file accompanies the image. The Release build excludes showcase data.

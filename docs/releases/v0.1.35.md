# Tasks 0.1.35

## Selection and editing

- Clicking the text, empty space, or padding in a task row selects the task. The native `List(selection:)` still controls the highlight.
- Star and completion buttons handle their own clicks. Drag and drop, keyboard navigation, and Delete still work.
- A dedicated SwiftUI container hosts the cached `NSTextView`, preserving text and Undo/Redo. The active container owns the delegate and task binding.
- Detaching the old container preserves the new container’s handlers. Closing a task cancels its pending focus request, and any deferred request checks editor ownership before running.
- Click directly in the title or description to edit or select text. Titles, descriptions, and subtasks remain editable on saved and completed tasks.
- Switching folders clears the open task and collapses Completed. Folders containing only completed tasks open without a selection. The storage schema is unchanged.

## Verification

Regression coverage includes editor ownership, detaching an old container, routing edits to the current task, Undo/Redo, field geometry, and row hit areas. UI scenarios cover different click targets, separate buttons, drag and drop, relaunch, and editing saved and completed tasks.

The app and test sources compiled. The app and tests were not run. Manual verification was pending for both appearances, windowed and full-screen modes, wrapping, caret position, and reopening a task.

The local universal DMG supports Apple Silicon and Intel on macOS 26 or later. It uses an ad-hoc signature and ships without Developer ID signing or Apple notarization. This build was prepared for local testing.

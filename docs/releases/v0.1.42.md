# Tasks 0.1.42 Pre-release

Build 43 includes all changes since the published [0.1.32 release](v0.1.32.md).

## Folders and task moves

- Each task has one primary folder: Inbox, This Week, Month, or a custom folder. New tasks are created in the open folder.
- This Week and Month are permanent folders. A date change leaves tasks in their folders.
- Today shows starred tasks across folders. All Tasks shows the library in creation order, newest first. Creating a task in either view puts it in Inbox. Creating it in Today also adds a star.
- Move tasks by dragging them to a sidebar folder or choosing **Move to Folder** from the row context menu or task toolbar menu. Dropping onto Today adds a star and preserves the primary folder.
- Drop destinations use a purple background with a white icon and title. The unfocused open folder remains gray with purple contents. Hovering leaves the current folder and task open. Canceling clears the temporary highlight.
- The list header counts active tasks matching the current search.

## Selection, editing, and deletion

- Click the text, empty space, or padding of a task row to open it. Star and completion buttons work independently.
- The open task stays selected while you edit the title or description. Fixed lost selection and ignored repeat clicks.
- Saved and completed tasks have editable titles, descriptions, and subtasks. Reattaching the native editor preserves the caret, selection, and Undo/Redo.
- Switching folders closes the task and collapses Completed. Folders containing only completed tasks open without a selection.
- Press Delete in the list to remove a task immediately. Deleting the open task clears selection and closes its editor, leaving neighboring tasks unselected. In text fields, Delete still edits text.

## List animations

- Inserting or deleting rows smoothly repositions the remaining tasks and avoids final-frame flashes and overlapping text.
- The first task in an empty list immediately gets a gray selection and focus in its title. Fixed a brief purple flash and a second disappearance of the first row.
- Today stars are yellow when filled, and unfilled icons remain legible in both appearances. Starring and renaming preserve creation order.
- Transitions respect Reduce Motion. Ordinary selection and folder changes retain their usual behavior.

## Library migration

On first launch, SwiftData migrates the library from V4 to V5. Custom folders are preserved. For tasks outside custom folders, the old week or month marker determines the new permanent folder. Other tasks remain in Inbox. The migration preserves identifiers, titles, descriptions, subtasks, dates, stars, completion state, deadlines, and calendar links.

## Installation and verification

- Requires **macOS 26 or later** on **Apple Silicon or Intel**.
- Download `Tasks-0.1.42-macOS-universal.dmg`, quit the previous version, and replace the app in Applications. Keep the existing sandbox container to preserve your library.
- The build uses local **ad-hoc signing** and ships without Developer ID signing or Apple notarization. macOS may restrict launching it on another Mac. You can build from source in Xcode.

Put the DMG and its SHA-256 file in the same folder and run:

```sh
shasum -a 256 -c Tasks-0.1.42-macOS-universal.dmg.sha256
```

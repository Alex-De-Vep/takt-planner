# Такт 0.2.17 / Takt 0.2.17

Предварительный выпуск для macOS и Android.

## macOS

Версия 0.2.17, сборка 67. Требуются macOS 26 и новее и Mac с Apple Silicon.

- Раздел «Сегодня» расположен перед «Входящими». Звёздочка действует до ручного снятия отметки.
- Заголовок, описание и подзадачи можно выделить мышью и скопировать одним фрагментом.
- Встроенная справка на русском и английском открывается из меню и настроек.
- ИИ-помощник поддерживает локальную модель, вход в ChatGPT и подключения облачных провайдеров.
- Официальный корневой сертификат GigaChat встроен в приложение. Доверие ограничено двумя HTTPS-адресами сервиса с проверкой имени сервера и цепочки.
- Очистка истории сохраняет выбранную облачную модель и начинает новый диалог.

DMG подписан ad-hoc. Для него отсутствуют подпись Developer ID и нотариализация Apple. Gatekeeper может ограничить открытие загрузки на другом Mac.

## Android

Тестовая версия 0.1.0, versionCode 1. Требуется Android 8.0 и новее.

- Задачи, папки, подзадачи, звёздочки, поиск, сроки и локальные напоминания.
- Вход в общий аккаунт и синхронизация с macOS. После первого обмена правки сохраняются в очередь при временной потере связи.
- Календарь устройства с выбором отображаемых календарей, созданием и редактированием разовых событий и удалением с подтверждением.
- ИИ-чат с выбором моделей и провайдеров, входом через браузер для ChatGPT и OpenRouter и подтверждением предложенных изменений.
- Обновлённые редакторы задач, подзадач и событий. Активное поле остаётся над клавиатурой, дополнительные поля добавляются по необходимости.
- Русский и английский интерфейсы, светлая, тёмная и системная темы.

APK собран в конфигурации debug и подписан тестовым ключом Android. Он предназначен для тестовой установки из файла. Для публикации в магазине потребуется release-сборка с постоянным ключом владельца приложения.

## Проверки

- Android `assembleDebug`, `testDebugUnitTest` и `lintDebug` завершились успешно.
- Локальные ссылки в README проверены. На скриншотах используются вымышленные задачи и события.
- Для macOS выполнены Release-сборка, проверка подписи и ресурсов, проверка DMG и монтирование только для чтения.
- HTTPS с кодом доверия GigaChat проверен на обоих адресах без API-ключа. Полная авторизация требует проверки с ключом пользователя.

## English

Takt 0.2.17, build 67, is a pre-release for macOS 26 and later on Apple Silicon. It includes persistent Today stars, whole-task text selection, help available from the menu and Settings, cloud AI providers, and the bundled GigaChat root certificate scoped to its two HTTPS endpoints.

The Android companion is version 0.1.0, versionCode 1, for Android 8.0 and later. It includes cloud task sync, deadline reminders, device calendars, AI chat, revised task and event editors, and improved keyboard visibility. The APK is a debug build signed with a test key for sideload testing. Store publication requires a release build signed with the owner’s permanent key.

The macOS DMG uses ad-hoc signing and has no Apple notarization. Check the SHA-256 files after downloading the installers. Quit the macOS app before replacing it. Android updates require the same signing key as the installed APK.

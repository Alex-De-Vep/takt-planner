# Takt 0.2.17 Pre-release

This pre-release includes the macOS app and a test build of the Android companion.

## macOS

Takt 0.2.17 (build 67) requires macOS 26 or later and a Mac with Apple Silicon.

- **Today** appears above **Inbox**. Starred tasks stay in Today until you remove the star.
- Select and copy a task’s title, description, and subtasks together.
- Open the built-in guide in English or Russian from the Help menu or Settings.
- Use the on-device AI assistant, sign in to ChatGPT, or connect another supported cloud provider.
- GigaChat uses a bundled official root certificate for its two HTTPS endpoints. Takt verifies the server hostname and certificate chain.
- Clearing chat history starts a fresh conversation and keeps your selected cloud model.

The DMG uses ad-hoc signing. macOS Gatekeeper may restrict opening it on another Mac. Quit Takt before replacing an installed copy.

## Android

Takt 0.1.0 (version code 1) requires Android 8.0 or later.

- Organize tasks in folders, add subtasks, search, and set deadlines with reminders.
- Use the same account on macOS and Android to sync tasks. After the first sync, edits made offline are queued and sent when you reconnect.
- Choose which device calendars to show. Create and edit one-off events and confirm before deleting them.
- Switch AI models and providers in chat. ChatGPT and OpenRouter support browser sign-in. Review and confirm changes proposed by the assistant.
- Edit tasks, subtasks, and events with the active field visible above the keyboard. Add optional fields when you need them.
- Choose English or Russian and use a light, dark, or system theme.

The APK uses Android’s debug signing key for test installation. Updating an existing APK requires a matching signing key.

## Verification

- The macOS release build, signature, bundled resources, and disk image passed verification. The DMG was mounted read-only for inspection.
- TLS verification succeeded on both GigaChat endpoints without an API key. To verify your account, use your API key in the app.
- The Android debug build, 21 unit tests, and lint checks completed successfully. Lint reported 15 warnings.
- Both installers have SHA-256 checksum files alongside the downloads.

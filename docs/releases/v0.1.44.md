# Tasks 0.1.44

Local preview **0.1.44, build 45**. Includes the [0.1.43 changes](v0.1.43.md).

## Subtasks

- Subtask titles wrap to the editor width and grow vertically without a line limit. Long text remains fully visible after reopening or completing the subtask.
- Completion and delete icons align with the top of multiline rows.
- The lower **Add Subtask** button now responds across the full row. An isolated UI test reproduced the old plain button missing clicks even on the label. The add, completion, and delete buttons now use the native borderless style.
- Pressing Enter in a filled subtask still adds the next one. Ordering, storage, and the data model are unchanged.

## Verification

Two UI tests and three storage checks passed.

- Added second and third subtasks through the lower button, including a click in the empty area to the right of the label. Verified the subtask count and text.
- Verified that a multiline title is fully visible, grows in height, and leaves room for the next row. Also checked Enter, ending editing, persistence after relaunch, completion of the long subtask, and deletion of another subtask. The test window screenshot was inspected.
- `ChecklistTests` checked migration and persistence after reopening, order and independent completion state, and cascading deletion limited to the deleted task’s subtasks.

UI checks used a separate bundle identifier, an isolated library with fictional data, and a substitute calendar. The full suite was not run. The shared scheme keeps UI tests off by default.

## Package

`Tasks-0.1.44-macOS-universal.dmg` requires macOS 26 or later on Apple Silicon or Intel. The packaging script checks both architectures, localization, the icon, entitlements, the signature, and the mounted DMG contents. A SHA-256 file accompanies the image.

Quit the previous version before replacing the app. The package uses a local ad-hoc signature and ships without Developer ID signing or Apple notarization.

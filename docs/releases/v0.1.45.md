# Tasks 0.1.45

Local preview **0.1.45, build 46**. Includes the [0.1.44 changes](v0.1.44.md).

## Subtask editing

- Fixed the caret jumping to the end when typing in the middle of a subtask. Each subtask keeps its own native editor across task detail updates. Saving a character skips rewriting text that already matches the model.
- Wrapping, automatic height, completed styling, Enter to add the next subtask, and the lower add button continue to work.
- External text updates preserve a valid selection range. Deleting a subtask or its parent task releases the corresponding cached editors.

## Verification

A UI test reproduced the old field inserting the first character in the middle and subsequent characters at the end. The same scenario passed with the new editor. The test uses navigation keys independent of keyboard layout.

Fourteen targeted checks passed.

- **Four UI tests** covered character-by-character insertion in short and multiline titles, repeated addition through the lower button, long-text display, Enter, relaunch, completion, and deletion.
- **Ten editor and storage checks** covered independent subtask editors, selection across reattachment, height measurement without changing text or caret, clearing the correct task’s editor cache, main editor attachment, ordering, migration, persistence, and cascading deletion.

Checks used a separate bundle identifier, an isolated library with fictional data, and a substitute calendar. The full suite was not run. The shared scheme keeps UI tests off by default.

## Package

`Tasks-0.1.45-macOS-universal.dmg` requires macOS 26 or later on Apple Silicon or Intel. The packaging script checks both architectures, localization, the icon, entitlements, the signature, and the mounted DMG contents. A SHA-256 file accompanies the image.

Quit the previous version before replacing the app. The package uses a local ad-hoc signature and ships without Developer ID signing or Apple notarization.

# Tasks 0.1.37

- The open task retains its native selection when you edit text or click empty list space. When the editor has focus, macOS shows the standard gray selection.
- Clicking the same task again reconciles native list selection even if the open task’s identifier has stayed the same. The list preserves editor focus and uses the system highlight.
- Rows leaving the list after completion, deletion, a move, or a search change can no longer restore stale selection. Switching folders still closes the task and collapses Completed.
- Storage and starring behavior are unchanged.

Regression scenarios use a real `NSTableView` to cover restoring selection, selecting a different task, retaining the inactive highlight, clearing navigation state, and removing a row. The UI scenario covers task creation, typing, clicking empty space, reopening the same row, and Delete.

The app and test sources compiled. The app and tests were not run. Manual UI verification was pending. The universal DMG was prepared for local testing with an ad-hoc signature and no Apple notarization.

# Takt 0.3.26

## Shared notes

Create and edit new cloud notes on Android and macOS using the same Takt account. Formatting, lists, links, and images sync between the two editors. The shared format applies to newly created notes and requires Takt Server 0.1.4 or later.

## Android 0.1.1

- Switch between Month, Week, and Day in Events. Month and Week mark dates with events and highlight today.
- Open notes from the bottom navigation. Record audio and format text in the note editor. Use Save when creating a note. Edits to an existing note save automatically.
- Long task and note titles wrap in lists and editors. Chat and Delete appear with the other task actions beneath the title.

The debug APK (version code 2) requires Android 8.0 or later. Updating an earlier build requires the same signing key.

## macOS 0.3.26

- Find Notes in the welcome screen. Backups include notes in the shared format.
- Add the Today widget to your desktop to see tasks from Today.

The DMG (build 110) requires Apple Silicon and macOS 26 or later. It is a test build signed with Apple Development and is not notarized.

## Verification

- macOS — 299 tests passed and 3 were skipped. The signatures of the app and widget were verified in the final DMG.

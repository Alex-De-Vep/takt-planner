# Такт 0.3.26 / Takt 0.3.26

## Общее

Новые облачные заметки можно создавать и редактировать на Android и macOS. Оформление текста, списки, ссылки и изображения синхронизируются через один аккаунт Takt. Общий формат применяется при создании заметки и требует Takt Server 0.1.4 или новее.

## Android 0.1.1

- В «Событиях» доступны месяц, неделя и день. В месяце и неделе отмечены даты с событиями, а текущая дата выделена акцентным цветом.
- Заметки открываются из нижней навигации. В редакторе заметки есть запись с микрофона и отдельная панель форматирования. «Сохранить» используется при создании, дальнейшие правки сохраняются автоматически.
- Длинные названия задач и заметок переносятся на следующие строки. В карточке задачи чат и удаление доступны в общем ряду под названием.

Тестовый APK (код версии 2) требует Android 8.0 или новее. Обновление поверх предыдущей сборки требует совпадающей подписи.

## macOS 0.3.26

- На приветственном экране есть карточка «Заметки». Резервные копии включают заметки в общем формате.
- Виджет «Сегодня» показывает задачи из этого раздела на рабочем столе.

DMG (сборка 110) требует Apple Silicon и macOS 26 или новее. Это тестовая сборка с подписью Apple Development, без нотариализации.

## English

New cloud notes sync rich text, lists, links, and images between the Android and macOS editors. The shared format requires Takt Server 0.1.4 or later.

- **Android 0.1.1** adds month, week, and day calendar views, a dedicated Notes tab, more compact editors, and multiline task and note titles. The debug APK requires Android 8.0 or later.
- **macOS 0.3.26** includes the shared note format and the Today widget. The Apple Development-signed DMG requires Apple Silicon and macOS 26 or later.

SHA-256 files accompany both installers.

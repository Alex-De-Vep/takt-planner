# Takt 0.3.27

## macOS 0.3.27

- Create rich notes with formatting, checklists, links, and images. Record voice notes or browser calls and send a recording for transcription after confirmation.
- Edit shared cloud notes on Mac and Android. Backups include notes and their attachments.
- Receive task and note changes through server-sent events, with polling as a fallback when the connection is interrupted or the server does not support events.
- Newly synced notes stay fully visible at the top of the list. Reading further down the list preserves the scroll position.
- Add the Today widget to your desktop to see your priority tasks.

The DMG requires Apple Silicon and macOS 26 or later. Build 111 is signed with Apple Development and is not notarized.

## Android 0.1.2

- Open rich notes from the bottom navigation and keep them in sync with macOS. New notes support shared formatting, lists, links, and images.
- Choose transcription settings independently from the chat model. Recordings appear in a dedicated card with recording and transcription controls.
- Switch between Month, Week, and Day in Events. Calendar views mark dates with events and highlight today.
- Long task and note titles wrap. The task and note editors group their actions above the formatting controls.

The debug APK requires Android 8.0 or later and uses version code 3. It updates earlier APKs signed with the same debug key.

## Takt Server 0.1.6

- Adds task and note event streams for prompt updates on macOS.
- Includes shared rich-note synchronization and migration 005 for event sessions.
- Older clients continue to use the existing sync endpoints. Shared rich notes require Server 0.1.4 or later; both event streams require Server 0.1.6.

The server archive contains source, migrations, configuration examples, and deployment scripts. Keep the existing server configuration and database when upgrading.

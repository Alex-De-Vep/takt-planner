# Tasks 0.2.13

Build 63 requires macOS 26 or later on Apple Silicon.

- Includes cloud task sync, a choice of local or cloud storage at first launch, and an in-app guide in English and Russian.
- The assistant supports a local model and optional ChatGPT sign-in. It proposes edits to text, tasks, and events for you to review and confirm.
- Approved changes to tasks and subtasks enter the sync queue. Each library keeps its own assistant conversation history.
- Includes the earlier editor improvements and the fix for a crash when macOS reports a date or time zone change on a background thread.

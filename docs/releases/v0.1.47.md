# Tasks 0.1.47

Local preview **0.1.47, build 48**. Includes the [0.1.46 changes](v0.1.46.md).

## Completed tasks

- Completing the selected task or another task preserves the collapsed Completed section and leaves the current task open. The section header and count update.
- Click the header to expand the section. Completing another task keeps an already expanded section open.
- Down Arrow moves from active to completed tasks only when the section is expanded.
- A section that disappears when emptied returns collapsed.
- A completed task can stay open while the section is collapsed.

## Verification

Four UI tests and four list behavior tests passed. UI checks covered completing the selected task or another task from the list, using the large completion button while the editor has focus, expanding and collapsing the section, retaining an expanded section, Down Arrow, and a previously empty section reappearing. List behavior checks covered selection when completing or reopening a task, switching folders, and folders with only completed tasks.

Checks used a separate bundle identifier, an isolated library, and a substitute calendar. The full suite was not run. The shared scheme keeps UI tests off by default.

## Package

`Tasks-0.1.47-macOS-universal.dmg` requires macOS 26 or later on Apple Silicon or Intel. The packaging script checks both architectures, localization, the icon, entitlements, the signature, and the mounted DMG contents. A SHA-256 file accompanies the image.

The package uses a local ad-hoc signature and ships without Developer ID signing or Apple notarization.

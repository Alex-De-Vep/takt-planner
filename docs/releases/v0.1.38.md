# Tasks 0.1.38

- Dragging a task over a folder highlights the destination independently and preserves the open folder’s native selection. Removed forced row emphasis, which previously made the active highlight jump between folders during a drag.
- The selected folder uses a gray background with a purple title and icon when the sidebar has no keyboard focus. With sidebar focus, it uses a purple background and white text.
- The drop destination uses a rounded purple background with a white title and icon. The open, unfocused folder keeps its gray highlight and purple accents. The temporary highlight clears when the pointer leaves or the drag ends. Task data and movement rules are unchanged.

The app and existing test sources compiled. The app and tests were not run. Manual checks were pending for focus changes between the sidebar, task list, editor, and search, for drag hover, cancellation, and completion, and for both appearances and inactive windows.

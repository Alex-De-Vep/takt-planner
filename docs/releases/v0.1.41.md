# Tasks 0.1.41

Build 42 includes [0.1.40](v0.1.40.md) and fixes a reproduced failure to animate the task list.

- The task column uses a persistent SwiftUI root that receives update transactions from its AppKit host.
- With `withAnimation` alone, the native list jumped 70 pt in one frame. Insertion and deletion now use 0.26-second native layer transitions while retaining the system List, selection, buttons, keyboard navigation, and drag and drop.
- The list captures the current appearance of visible rows before results change. This prevents a flash of their final positions and lets a new action start from the positions reached during an in-progress transition.
- On insertion, space opens before the new row appears. On deletion, the row disappears before its neighbors fill the gap. The removed row’s snapshot stays independent of the deleted SwiftData model.
- Search, folder navigation, and ordinary selection changes keep their usual behavior. Reduce Motion disables insertion and deletion transitions.
- Deleting the open task clears selection and closes the editor, leaving neighboring tasks unselected and the Completed section in its previous state. A save failure keeps the task open. Deleting another task leaves the current editor open.
- The data schema, folder rules, and task order are unchanged.

## Verification

Runtime checks used an isolated SHOWCASE build with a separate bundle identifier and in-memory tasks and calendar. Checks covered creation, Delete, clearing selection, selecting a task again by click or arrow key, and switching folders. Frame-by-frame recordings showed intermediate row positions and verified fixes for final-frame flashes and overlapping text.

Twenty-nine checks passed across five suites. Automated checks measured intermediate positions in a real `NSTableView`, including a second insertion before the first transition finished. Selection, editor, and drag-context tests used isolated data. UI regression sources cover deletion without automatically opening a neighboring task.

The universal Apple Silicon and Intel DMG was prepared for local testing. The packaging script checks the app name, icon, localization, entitlements, ad-hoc signature, architectures, checksum, and DMG contents.

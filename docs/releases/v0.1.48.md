# Tasks 0.1.48

Local preview **0.1.48, build 49**. Includes the [0.1.47 changes](v0.1.47.md).

## Task toolbar menu

- The ellipsis menu sits immediately after the deadline button, with consistent spacing between task actions.
- The ellipsis uses the same adaptive primary color as neighboring icons in light and dark appearance.
- Flexible space follows the full action row in every calendar mode. Calendar overlay mode aligns the row with its own header.
- Menu items, moving a task, and deletion with confirmation are unchanged.

## Verification

Fifteen checks passed covering toolbar structure and geometry, search, the subtask and deadline buttons, and calendar modes. The existing UI scenario for the large task buttons passed and was rerun after the menu color update. The final screenshot confirmed the ellipsis position and primary color in dark appearance.

The existing `ToolbarSearchTests.searchTextDoesNotOverlapIconsAtSupportedWidths()` test failed. The vertical centers of the search field and icon differed by 0.5 pt against a tolerance strictly below 0.5 pt. The search field and its test are unchanged in this release.

Checks used a separate bundle identifier, an isolated library, and a substitute calendar. The full suite was not run.

## Package

`Tasks-0.1.48-macOS-universal.dmg` requires macOS 26 or later on Apple Silicon or Intel. The packaging script checks both architectures, localization, the icon, entitlements, the signature, and the mounted DMG contents. A SHA-256 file accompanies the image.

The package uses a local ad-hoc signature and ships without Developer ID signing or Apple notarization.

# Tasks 0.1.49

Build 50 requires macOS 26 or later and supports Apple Silicon and Intel.

- Sign in to sync tasks. Cloud mode uses a separate task library.
- Choose local or cloud storage at first launch. The app includes an English and Russian guide.
- Text selection in task descriptions is improved. Tasks stay in Today until you remove the star.
- Fixed a crash when macOS reports a date or time zone change on a background thread.

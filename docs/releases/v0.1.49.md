# Задачи 0.1.49 / Tasks 0.1.49

Сборка 50 для macOS 26+, Apple Silicon и Intel.

- Добавлены облачный аккаунт, синхронизация задач и отдельная библиотека для облачного режима.
- При первом запуске можно выбрать локальное или облачное хранение. В приложении появилась справка на русском и английском.
- Улучшено выделение текста в описании задачи. Отметка «Сегодня» сохраняется до ручного снятия звезды.
- Исправлено аварийное завершение при смене дня и часового пояса, когда системное уведомление приходит из фонового потока.

Build 50 for macOS 26+ on Apple Silicon and Intel adds optional cloud task sync, a first-run storage choice, and in-app help in Russian and English. It also improves task description selection, keeps stars until manually removed, and fixes a crash when macOS delivers a date or time zone change in the background.

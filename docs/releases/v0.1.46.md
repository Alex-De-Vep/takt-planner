# Tasks 0.1.46

Local preview **0.1.46, build 47**. Includes the [0.1.45 changes](v0.1.45.md).

## Text selection and focus

- Title and description selections collapse only when the editor actually loses keyboard focus. The caret moves to the end of the selection. An existing caret position is preserved when there is no selection.
- Closing the active editor or switching tasks follows normal focus-loss behavior. Switching tasks applies no extra selection reset.
- Ordinary updates and reattaching the same editor preserve editing state. Undo/Redo stays with the document.
- After focus moves, the editor redraws the insertion point to remove a lingering blinking caret. The deferred redraw checks whether the editor has regained focus.
- Subtask text selection is unchanged.

## Task detail buttons

- Fixed missed clicks on the large Today and Completed buttons. The buttons use the native borderless style, and their decorative outline lets clicks pass through.
- A UI test toggles both buttons in both directions while the editor is active, clicks the center and free edges, and verifies that the list row updates while the task stays open.

## Verification

Ten editor tests and five UI tests passed.

- Editor tests verified the actual `firstResponder`, selection collapse, retaining a caret with no selection, text, and Undo/Redo when focus moves. Two scenarios were parameterized for both fields.
- Additional checks covered closing the focused editor, reattachment, retaining selection in a previously unfocused editor, caching, undo history, independent documents, and multiline measurement.
- UI tests covered editing mid-title and mid-description after losing focus and returning to the task, caret regressions in short and multiline subtasks, and both large action buttons.

After the redraw fix, all ten editor tests and both title and description UI scenarios passed again. Screenshots confirmed the old selection and caret cleared from inactive fields. Tests used a separate bundle identifier, an isolated library with fictional data, and a substitute calendar. The full suite was not run. The shared scheme keeps UI tests off by default.

## Package

`Tasks-0.1.46-macOS-universal.dmg` requires macOS 26 or later on Apple Silicon or Intel. The packaging script checks both architectures, localization, the icon, entitlements, the signature, and the mounted DMG contents. A SHA-256 file accompanies the image.

Quit the previous version before replacing the app. The package uses a local ad-hoc signature and ships without Developer ID signing or Apple notarization.

# Tasks 0.1.39

Build 40 includes the changes from [0.1.38](v0.1.38.md).

- Task insertion and deletion move neighboring rows over 0.26 seconds. Scrolling to a new task is animated and the editor receives focus immediately. The app respects Reduce Motion.
- The unfilled Today star uses the adaptive primary color. Starred tasks retain their yellow star.
- The active Today action also uses a yellow star and retains its existing text and background colors.

The app and test sources compiled with `build-for-testing`. Tests and visual checks were not run. The release packaging script checks the icon, localized names, both architectures, entitlements, local ad-hoc signature, and contents of the read-only mounted DMG. The build supports Apple Silicon and Intel and ships without Apple notarization.

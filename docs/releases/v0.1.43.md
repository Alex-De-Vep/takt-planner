# Tasks 0.1.43

Local preview **0.1.43, build 44**, for manual testing. Includes the [0.1.42 changes](v0.1.42.md).

- Opening a folder starts the list at the top, including the first group header in Today. Task edits and star changes within the open folder preserve the scroll view.
- The full row of the lower **Add Subtask** button is clickable, including the transparent padding. Its minimum hit height is 32 pt.
- Sidebar drop highlights retain their 10 pt horizontal insets.
- Subtask titles are still displayed on one line.

## Verification and installation

The app and test sources compiled with `build-for-testing`. Tests and visual checks for these fixes were not run. The click area and initial scroll position were pending verification in the installed app. The release packaging script checks both architectures, localization, the icon, entitlements, the signature, and the mounted DMG contents. A SHA-256 file accompanies the image.

`Tasks-0.1.43-macOS-universal.dmg` requires macOS 26 or later on Apple Silicon or Intel. Quit the previous version before replacing the app. The package uses a local ad-hoc signature and ships without Developer ID signing or Apple notarization.

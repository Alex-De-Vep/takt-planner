# Tasks 0.1.31 Public Preview

The first public preview of a native macOS task planner. The source code is available under Apache 2.0.

- Organize tasks in folders and Today, plan by week or month, and set deadlines and local notifications.
- Add a title, a multiline plain-text description, and subtasks. Wrapped descriptions no longer overlap the subtask section.
- View the system calendar by day, three days, or week. Create and edit one-off events and link events to tasks.
- The app uses local SwiftData storage and supports light and dark appearance and English and Russian interfaces.

## Installation

Requires **macOS 26 or later** on Apple Silicon or Intel. Open the DMG, drag the app into Applications, and eject the disk image.

The preview is ad-hoc signed and ships without Developer ID signing or Apple notarization. macOS may block the downloaded app at launch. You can build it from source in Xcode.

## Limitations

The task library is local to each device. Recurring events and events in read-only calendars can be viewed. Connected calendar providers can sync their events independently.

## Verification

The app and test sources compiled. Editor checks and screenshots used fictional in-memory data and required no access to personal calendars. The test suite was not run. The Release build excludes showcase mode.

The DMG was mounted read-only. Both architectures, the app icon, names, permissions, and local signature were checked. To check the download, put the DMG and its checksum file in the same folder and run:

```sh
shasum -a 256 -c ./*-0.1.31-macOS-universal.dmg.sha256
```

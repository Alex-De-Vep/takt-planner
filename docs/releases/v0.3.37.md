# Takt 0.3.37

## macOS 0.3.37

- Connect AI providers in **Settings → Assistant**, choose which models appear in the picker, and set separate defaults for chat and transcription. The chat picker and settings share the same selection.
- Record audio in one session. After you approve transcription, Takt prepares and sends long recordings one part at a time, then combines the transcript in the note.
- Move tasks and notes by dragging them onto a folder or using the folder picker above the title. Delete tasks and pin or trash notes from the editor toolbar.
- All Notes and Recently Deleted use the same sidebar selection as folders. The highlight switches immediately. Note toolbar buttons have consistent spacing.
- Pasted text adopts the note’s font, size, and color immediately. Links, basic emphasis, and images are preserved. Save errors appear in the affected note, where the draft stays available.
- The bottom of the sidebar shows sync progress, success, or an error. Click an error for details and a retry action.

Build 121 requires Apple Silicon and macOS 26 or later. The DMG is signed with Apple Development and is not notarized.

## Android 0.1.3

- The Tasks and Notes headers show a warning when sync fails or the server rejects changes. Tap it to see the cause, pending or rejected changes, and a sync action.
- The notes trash explains the 30-day retention period. Expired notes are no longer offered for restoration.

The debug APK requires Android 8.0 or later and uses version code 4. It updates earlier APKs signed with the same key.

## Compatibility

This release contains macOS and Android clients. Shared rich notes require Takt Server 0.1.4 or later. Server 0.1.6 supports task and note event streams.

# Tasks 0.1.33

## Folders and task moves

- Every task has one primary folder: Inbox, This Week, Month, or a custom folder. This Week and Month are now permanent folders.
- New tasks are created in the selected folder. Creating a task from Today adds a starred task to Inbox. Creating one from All Tasks adds it to Inbox.
- Today shows starred tasks across folders. All Tasks lists the entire library by creation date, newest first, with completed tasks at the bottom.
- Move tasks by dragging them to a sidebar folder or using the task’s context or toolbar menu. The current folder has a checkmark. Dropping onto Today adds a star and leaves the primary folder intact. Repeating the drop keeps the star. All Tasks is a view of the library and accepts no drops.
- The header count includes active tasks matching the current search.
- Moving the selected task out of the open folder selects a neighboring active task. A collapsed Completed section stays collapsed.

## Data migration

The one-time SwiftData V4 → V5 migration preserves existing custom folders. For tasks outside custom folders, old week or month markers determine the new permanent folder regardless of when they were set. All other tasks stay in Inbox.

Moving a task preserves its identifier, creation date, description, subtasks, star, completion state, deadline, notifications, and calendar links.

## Verification

The app and test sources compiled with `build-for-testing`. Regression coverage includes migration, task creation and moves, active-task counts, selecting a neighbor, save failures, and local drag references. The app and tests were not run. Manual UI verification was pending.

The universal build supports Apple Silicon and Intel on macOS 26 or later. It uses a local ad-hoc signature and ships without Developer ID signing or Apple notarization.

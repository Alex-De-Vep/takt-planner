# Tasks 0.1.34

- Switching folders clears the open task and collapses Completed in a single transaction.
- A folder with only completed tasks stays without a selection on first entry and when revisited.
- Selecting the current folder again keeps the open task. Creating a task or opening it from a calendar link or notification still selects that task.
- Completing the open task keeps it on screen. The storage schema is unchanged.

Regression coverage includes folder navigation and the Completed section collapsing. The app and test sources compiled. The app and tests were not run. Manual UI verification was pending.

The universal local build supports Apple Silicon and Intel on macOS 26 or later. It uses an ad-hoc signature and ships without Developer ID signing or Apple notarization.

# Скриншоты для README

На главной странице широкий кадр macOS показывает рабочее окно. Четыре портретных кадра Android показывают список, карточку задачи, календарь и ИИ-чат. Чат macOS показан отдельно, рядом с открытой задачей. На снимках Android во всех README используется английский интерфейс. Русский README показывает рабочее окно macOS на русском.

## Android

Текущие кадры сняты в Android-эмуляторе в светлой теме. Отдельная сборка открывала обычные экраны с вымышленной библиотекой и календарём. Для повторной съёмки можно использовать демонстрационный аккаунт на телефоне или эмуляторе.

| Файл | Что показать |
| --- | --- |
| `android-today-en.png` | Откройте **Today** с 4–5 задачами. У первой виден срок, а на экране — обычные кнопки навигации. |
| `android-task-en.png` | Откройте первую задачу из списка. В кадре должны поместиться название, короткое описание, срок и три подзадачи, одна из них отмечена выполненной. Сверните клавиатуру. |
| `android-calendar-en.png` | Откройте вкладку **Events** на дне, в котором есть 2–3 вымышленных события. Оставьте видимыми выбранную дату и расписание с часами. |
| `android-assistant-en.png` | Откройте **Chat**. Покажите короткий запрос и предложение с названием задачи и подзадачами до подтверждения. |

## macOS

Для главной страницы нужен новый `workspace-light-en.png`. Снимите целое окно: папки слева, список и открытая задача с подзадачами посередине, календарь справа. Выберите ту же задачу, что и на Android.

Для русского README можно повторить композицию в `workspace-light-ru.png`. `workspace-dark-ru.png` и `settings-ru.png` относятся к дополнительным материалам. Снимок настроек используется в [руководстве](../settings.md).

Для `macos-assistant-en.png` переключите правую панель с календаря на ИИ-чат и оставьте ту же задачу открытой. На обоих кадрах чата показана вымышленная переписка с предложением **Publish the new collection** до подтверждения.

Демонстрационные сборки macOS можно подготовить командой `python3 apps/macos/scripts/prepare_showcase.py`. Откройте нужный вариант из `apps/macos/.build/showcase/`, выберите первую задачу во «Входящих» и откройте календарь. Сборки используют вымышленные данные в памяти. [Подробности](../development.md#скриншоты).

## Общие данные для кадров

Создайте четыре задачи во **Inbox** и поставьте звезду каждой, чтобы они появились в **Today**. Главную задачу создайте последней, чтобы она оказалась выше остальных при сортировке по дате создания.

| Task | Deadline |
| --- | --- |
| Prepare the new collection | Tomorrow, 6:00 PM |
| Collect ideas for the weekend | — |
| Review the meeting notes | — |
| Choose a book for November | — |

Описание задачи **Prepare the new collection**:

> Bring everything together for launch. Start with the essentials and check the details before publishing.

- [x] Gather references
- [ ] Prepare photographs
- [ ] Review the description

Создайте три события в демонстрационном календаре на день съёмки и выберите этот день на экране **Events**.

| Event | Time |
| --- | --- |
| Collection focus time | 10:00 AM–12:00 PM |
| Review ideas | 2:00–3:00 PM |
| A walk without the phone | 6:00–7:00 PM |

Присылайте исходные PNG в полном разрешении, по одному файлу на экран. Для Android оставьте обычную портретную ориентацию, без рамок и коллажей. Для macOS снимите только окно приложения. Проверьте, что в кадре только вымышленные задачи и события и что поверх окна нет системных уведомлений.

## Windows

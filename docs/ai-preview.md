# ИИ-помощник Takt для macOS

Откройте **Настройки → Помощник → Подключить ИИ-провайдер**. После подключения добавьте нужные модели в список и выберите модель для чата и для расшифровки. Выбор модели чата также доступен в самом разговоре.

История хранится на Mac. При отправке провайдер получает сообщение и выбранный контекст. Перед отправкой аудио на расшифровку приложение запрашивает подтверждение. [Конфиденциальность](privacy.md)

Информация о ранней экспериментальной версии сохранилась в описании выпуска. [Версия 0.2.13](releases/v0.2.13.md)

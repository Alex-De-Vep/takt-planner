# Задачи AI Preview / Tasks AI Preview

Экспериментальная ветка `codex/ai-assistant`, основанная на 0.1.48. Версия Preview: 0.2.0, build 50. GitHub-релиз не публикуется.

## Требования и установка

Только Mac с Apple M1 или новее, macOS 26+. Установленный Xcode и Metal Toolchain пользователю не нужны: GPU-ресурсы компилируются и включаются в приложение при сборке. Проверка проводилась на Mac с 16 GB RAM. Минимальная память пока не заявлена; устройства с 8 GB отдельно не проверялись. При системной нехватке памяти генерация останавливается, модель выгружается, переписка сохраняется.

Установите `Задачи AI Preview.app` рядом с обычными «Задачами». Bundle ID — `local.planner.AIPreview`; библиотека и настройки отдельные. Рабочие задачи основной версии автоматически не импортируются. Схема SwiftData V5 не менялась.

Откройте кнопку чата перед календарём. Справа может быть только календарь или помощник. Нажмите «Скачать и включить»: Qwen3.5-4B 4-bit загружается с Hugging Face, проверяется SHA-256, затем подготавливается в памяти. Все файлы закреплены ревизией `0e7ffd5c629ef7719d4cbc04069232580bfa9d9c`. Размер около 3,06 GB относится к диску, не к RAM. Веса в DMG не включены.

После установки обработка текста локальная; облачного fallback и отправки переписки провайдеру модели нет. Загрузка файлов и открытие внешней страницы лицензии используют сеть. История хранится локально в контейнере приложения, не шифруется отдельно от системной защиты диска. Полные запросы не записываются в диагностический журнал приложения.

## Сценарий

1. Напишите: «Во Входящие добавь подготовку макета с подзадачами собрать референсы и нарисовать эскиз».
2. Или: «Создай встречу с дизайнером 30 октября 2026 в 15:00 на полчаса, напомни за 10 минут».
3. При недостающем времени помощник задаёт вопрос и предлагает варианты. Они не означают проверенную занятость календаря.
4. Проверьте и при необходимости измените карточки. Папка, сроки, календарь и напоминания видны до сохранения.
5. Нажмите «Создать». Созданные карточки получают ссылку «Открыть». Применение не переключает текущую папку автоматически.

Enter отправляет, Shift+Enter вставляет строку. История и черновик сохраняются. Метки папки и выбранной задачи можно исключить из контекста. Снимок контекста фиксируется при отправке.

Для записи события понадобится разрешение системного календаря: подключите его в существующей панели или настройках. При разрешении события создаются в настоящих системных календарях; не используйте личные календари для автоматических тестов.

## Что включено

Новые задачи с описанием, подзадачами, сроком и отметкой «На сегодня»; самостоятельные разовые события; планирование времени новой или выбранной задачи. Изменение предложений сообщениями и полями прямо в карточке чата, без модальных окон. Создание только после явного применения. Проверка доступных папок/календарей перед записью.

Настройки: текущая или заданная папка, длительность и напоминание события, выключение помощника, удаление модели, очистка истории. Уведомления задач следуют существующим общим настройкам сроков.

## Границы первой версии

Нет записи бесед, облачной модели, Intel, повторяющихся событий и изменения/удаления существующих объектов через ИИ. Срок задачи не является событием. «Сегодня» не заменяет основную папку. Качество небольшой модели не гарантирует верного понимания каждого запроса — обязательно проверяйте предложения.

Ошибки/неполный JSON не исполняются. У каждого действия свой UUID; созданные задачи не повторяются при повторной попытке. EventKit и SwiftData не имеют общей транзакции: после известного успешного создания события повторяется только сохранение связи. Если приложение завершилось во время календарной записи и её результат неизвестен, автоматический повтор блокируется до ручной проверки. Глобального автоматического отката всего пакета нет.

История и журнал исполнения используют отдельный JSON с версией формата и атомарной записью. Удаление модели не удаляет историю/задачи. Очистка истории не удаляет созданные объекты.

## Сборка и проверка

```
python3 scripts/generate_project.py
xcodebuild -resolvePackageDependencies -project Planner.xcodeproj -scheme Planner
python3 scripts/build_ai_preview.py
```

Зависимость MLX Swift LM закреплена на 2.31.3, транзитивные версии — в Package.resolved. Для сборки нужен Xcode 26.5 и компонент Metal Toolchain (`xcodebuild -downloadComponent MetalToolchain`). Код модели подключён в процесс, Python/Ollama/отдельный сервер пользователю не нужны.

Тесты AssistantTests используют fake backend и FakeCalendarStore. AssistantModelSmokeTests включаются только схемой PlannerAIModelSmoke и читают отдельные тестовые веса из `.build/ModelCache`; это вымышленные запросы без доступа к личным календарям. Для запуска UI/тестов используйте SHOWCASE и отдельные bundle ID/хранилище.

Артефакт — arm64 DMG и SHA-256. Подпись ad-hoc, без Developer ID и нотариализации. Уведомления об авторстве Swift-пакетов включены в приложение; модель имеет собственные условия Apache 2.0.

## English

Tasks AI Preview is an isolated Apple-silicon-only build for macOS 26+. Install it alongside Tasks; it has a separate bundle ID, preferences and task library. Open the chat button to download and enable the pinned Qwen3.5-4B 4-bit model (~3.06 GB on disk). Model files are verified before loading. No Xcode installation is needed to run the packaged app.

Inference runs on your Mac. Review editable proposals before creating tasks, subtasks, deadlines or one-time calendar events. Missing event dates/times require clarification. Events may be linked to a new or selected task. Calendar write access must be granted through the existing calendar UI. Successful operations are journaled; uncertain interrupted calendar writes are not blindly retried.

Settings include the default folder, event duration/reminder, disabling or deleting the model and clearing chat history. Deleting model files/history does not delete created tasks or events. Task schema V5 remains unchanged. No Intel, recording, cloud fallback, recurrence or editing/deleting existing objects through AI in this preview.

Build with `python3 scripts/build_ai_preview.py`. This produces a local arm64 DMG with ad-hoc signing, without Developer ID notarization. No GitHub Release is published by the script.

## Результаты локальной проверки

- Выбрана Qwen3.5-4B: 2B-кандидат ошибался на новых формулировках и уточнении дат.
- Реальная 4B-модель проверена на пяти вымышленных запросах: подзадачи, событие с заданным интервалом/напоминанием, недостающее время, ответ на уточнение и английский запрос.
- 51 целевая проверка в совокупности: логика помощника/установки/журнала, фактический запуск модели, регрессии списка, выделения и нативного редактора. Полный набор UI-тестов не запускался.
- Вручную проверены загрузочный экран, ввод по Enter, редактирование предложения, создание задачи с подзадачами, открытие созданного объекта и переключение календарь/чат.
- Системные календари для тестов не используются. Реальная запись EventKit остаётся для ручной проверки пользователем.
- В старом полном CalendarAndEditorTests обнаружена несовместимая с текущим SDK заглушка RecurrenceEventStub (создание EKEvent без eventStore). Этот полный набор не считается пройденным; целевые тесты и регрессии запускались отдельно.

# Задачи для Android

Нативный клиент на Kotlin и Jetpack Compose для Android 8.0 и новее. Проект открывается отдельно из папки `android/`, а [протокол синхронизации](../server/docs/API.md) хранится в общем репозитории с сервером и клиентом macOS.

- Задачи, описание, подзадачи, папки, поиск, раздел «Сегодня» и выполненные задачи.
- Сроки с датой и временем, список сроков и уведомления. Напоминания включаются в настройках. Для даты без времени используется 09:00 в часовом поясе срока. Android может доставить уведомление позже.
- Из карточки задачи можно открыть системное приложение календаря с заполненным названием и описанием события.
- Локальная библиотека работает без аккаунта. Для облачной библиотеки войдите в существующий аккаунт после её настройки в приложении macOS. Укажите тот же HTTPS-адрес сервера и подключитесь к той же сети, если сервер закрытый.
- Изменения в облачной библиотеке сохраняются офлайн и отправляются, пока приложение открыто. Локальная и облачная библиотеки хранятся отдельно. Управление аккаунтом и вложениями доступно в клиенте macOS.

## Сборка

Откройте эту папку в Android Studio. Для сборки нужны JDK 17, Android SDK Platform 36 и Android SDK Build-Tools 36.0.0. Выберите эмулятор или подключите Android-устройство и нажмите **Run**.

Из командной строки в папке `android/`:

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest
```

APK для проверки появится в `app/build/outputs/apk/debug/app-debug.apk`.

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

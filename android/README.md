# Задачи для Android

Нативный клиент на Kotlin и Jetpack Compose для Android 8.0 и новее. Проект открывается из папки `android/`. Клиенты Android и macOS используют [общий протокол синхронизации](../server/docs/API.md).

- **Задачи.** Списки, поиск, звёзды, выполненные задачи и подзадачи. В настройках можно включить напоминания и выбрать время для сроков без времени. По умолчанию это 09:00 в часовом поясе срока.
- **События.** Повестка из выбранных календарей Android. Разовые события можно создавать и редактировать в Planner. В настройках выбирается календарь для новых событий. Подключите один календарный аккаунт на Android и Mac, чтобы видеть одни и те же события.
- **Чат.** Нажмите «Выбрать ИИ-модель», чтобы переключиться между сохранёнными подключениями или добавить провайдера. Ключи хранятся на устройстве под защитой Android Keystore, отдельно для каждого аккаунта Planner. При отправке сообщения провайдер получает текст чата и контекст явно выбранной задачи. Изменения по предложениям сохраняются после подтверждения.
- **Интерфейс.** В настройках доступны светлая и тёмная темы, русский и английский языки. Для темы и языка можно использовать настройки устройства.

### Облачные подключения

- ChatGPT и OpenRouter поддерживают вход через браузер. OpenRouter также принимает API-ключ.
- LiteLLM принимает HTTPS-адрес шлюза и виртуальный ключ. Для GitHub Copilot нужен доступный с телефона HTTPS-адрес моста Copilot и его ключ. Мост должен отвечать на `/v1/models` и `/v1/chat/completions`, как мост клиента macOS.
- Подключения по ключу доступны для MiniMax M Plan, MiniMax API, Claude, Gemini, DeepSeek, Mistral, GLM, Grok, QwenCloud, Kimi, YandexGPT Pro и GigaChat. YandexGPT дополнительно требует ID каталога. Для GigaChat выберите область доступа ключа. [Корневой сертификат Минцифры](https://developers.sber.ru/docs/ru/gigachat/certificates) включён в приложение и применяется к `api.giga.chat` и `ngw.devices.sberbank.ru`. При необходимости для MiniMax, GLM и QwenCloud укажите идентификаторы моделей вручную.

При первом запуске войдите в аккаунт Planner или зарегистрируйтесь и подтвердите почту. Android автоматически использует тот же сервер Planner, что и macOS, и открывает задачи после первой успешной синхронизации. После первой синхронизации изменения при временной потере связи сохраняются в очереди этого аккаунта и отправляются при следующем обмене.

## Сборка

Откройте папку `android/` в Android Studio. Нужны JDK 17, Android SDK Platform 36 и Android SDK Build-Tools 36.0.0. Выберите эмулятор или подключите Android-устройство и нажмите **Run**.

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
